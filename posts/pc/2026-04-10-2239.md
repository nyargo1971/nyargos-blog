<p>- 数値範囲：</p>

<p>(2).内部的な数値<br />x座標：`-100 ～ 100`<br />y座標：`-100 ～ 100`<br />半径r：`9 ～ 100`<br />- 内部的な数値は、実数とする<br />- 内部的な数値は、正規化する</p>
<p>## 正規化</p>
<p>NNモデルに入力されるヒント値 x は<br />以下の式で 0〜1 に正規化してから使用する。</p>
<p>x_norm = (x - HINT_MIN) / (HINT_MAX - HINT_MIN)</p>
<p>NN005およびNN007は<br />この x_norm を入力値として使用する。</p>
<p><br />- 各ターンでは、 environment.pyが、ランダム関数による整数値**ヒント値** をNNモデルに与える。<br />- ヒント値は、1つ与えられる<br />- ヒント値の数値の範囲は、2.1-(1)「人間が入力する秘密の真円の値」の内のx座標と同じ範囲で、かつ整数とする。</p>
<p>- 各NNモデルは、ヒント値に対して、各モデル用の重み値データを取り寄せて、そのデータか判断して、以下の情報を返す。</p>
<p>INSIDE : ヒント値は境界内にある<br />OUTSIDE : ヒント値は境界内に無い（＝境界外にある）</p>
<p>environment判定式：</p>
<p>(x_hint - target_x)^2 + (0 - target_y)^2 &lt;= r^2</p>
<p>を満たす場合</p>
<p>INSIDE</p>
<p>それ以外</p>
<p>OUTSIDE</p>
<p>(3) 定数定義</p>
<p>HINT_MIN = -99<br />HINT_MAX = 99</p>
<p>TURN_MAX = 1000 # デバック用の短めのターン数。収束は期待しない。config.pyで書き換え可能</p>
<p>ETA_NN005 = 0.05<br />ETA_NN007 = 0.02</p>

<p>---<br /># 4. モデル仕様</p>
<p>## 4.1 NN005（1層モデル）</p>
<p>特徴：<br />単一パラメータ μ により境界値を推定する。</p>
<p>入力：<br />ヒント値 x</p>
<p>x は正規化値 x_norm を使用する。</p>
<p>教師信号：<br />INSIDE / OUTSIDE</p>
<p>学習更新：</p>
<p>μ ← μ + η × s × (x − μ)</p>
<p>ここで</p>
<p>s = +1 （INSIDE）<br />s = −1 （OUTSIDE）</p>
<p>INSIDE の場合、μ はヒント値 x に近づく方向へ更新される。 <br />OUTSIDE の場合、μ はヒント値 x から離れる方向へ更新される。</p>
<p>この更新は単一パラメータによる<br />簡易境界推定モデルとして機能する。</p>
<p>---</p>
<p>## 4.2 NN007（2層モデル）</p>
<p>### NN007 推定境界計算</p>
<p>NN007に入力される x は<br />必ず正規化値 x_norm を使用する。</p>
<p>f(x) の x は<br />すべて x_norm を意味する。</p>
<p><br />NN007は二次関数</p>
<p>f(x) = ax² + bx + c</p>
<p>を用いて境界を推定する。</p>
<p>境界は以下の方程式の解として求める。</p>
<p>ax² + bx + c = 0</p>
<p><br />解は次の2つである。</p>
<p>- x1 = (-b - √(b² - 4ac)) / (2a)<br />- x2 = (-b + √(b² - 4ac)) / (2a)</p>
<p>この2つの値を **NN007の推定境界**とする。</p>
<p><br />### GUI表示</p>
<p>GUIでは以下の2点を表示する。</p>
<p>- (x1 , 0)<br />- (x2 , 0)</p>
<p>これらは **NN007モデルが推定したx軸との接点位置**を表す。</p>
<p>### 判別式チェック1(a=0(NN007破損)を回避するための条件つけ)<br />判別式1</p>
<p>|a| &lt; 1e-6<br />の場合は**更新をスキップ**する。</p>
<p>### 判別式チェック2(解が存在しない場合)<br />判別式2</p>
<p>b² - 4ac &lt; 0</p>
<p>の場合、実数解は存在しない。</p>
<p>この場合は **推定境界なし**として扱い、<br />GUIには点を表示しない。</p>
<p>### NN007 学習更新</p>
<p>NN007は以下の二次関数モデルを使用する。</p>
<p>f(x) = ax² + bx + c</p>
<p><br />ヒント値 x に対して生成される特徴量は以下とする。</p>
<p>- x²<br />- x<br />- 1</p>
<p><br />モデルの出力は</p>
<p>f(x) = a·x² + b·x + c</p>
<p>である。</p>
<p><br />environment の判定結果に基づき、教師信号 s を定義する。</p>
<p>- INSIDE : s = +1<br />- OUTSIDE : s = -1</p>
<p><br />学習更新は以下の式で行う。</p>
<p>誤差 e を</p>
<p>e = s - f(x)</p>
<p>と定義する。</p>
<p><br />学習率 η を用いてパラメータを更新する。</p>
<p>- a ← a + η × e × x²<br />- b ← b + η × e × x<br />- c ← c + η × e</p>
<p><br />η（学習率）は config.py で定義する。</p>
<p>### パラメータ制約</p>
<p>円の断面形状に近づけるため、<br />NN007の係数 a は負の値を維持する。</p>
<p>a &gt; 0 になった場合は</p>
<p>a ← -|a|</p>
<p>として補正する。</p>
<p>### パラメータ制限</p>
<p>NN007の係数は以下の範囲に制限する。</p>
<p>-1 ≤ a ≤ -0.001<br />-2 ≤ b ≤ 2<br />-2 ≤ c ≤ 2</p>
<p>更新後に範囲を超えた場合は<br />境界値にクリップする。</p>
<p>## 4.3 モデル初期値</p>
<p>各NNモデルの初期パラメータは以下とする。</p>
<p><br />### NN005 初期値</p>
<p>- μ005（推定境界中心） : 0.5<br />- η（学習率） : 0.05</p>
<p><br />### NN007 初期値</p>
<p>NN007のモデル関数は</p>
<p>f(x) = ax² + bx + c</p>
<p>とする。</p>
<p>初期パラメータは以下とする。</p>
<p>a = -0.01<br />b = 0<br />c = 0<br />---</p>

<p># 8-1. environment仕様</p>
<p>environmentの役割：</p>
<p><br />・ヒント生成<br />・正解/不正解の判定<br />・エラー入力チェック</p>
<p><br />入力：</p>
<p><br />hint<br />target</p>
<p>ヒント値 x は<br />NNに渡す前に</p>
<p>x_norm = (x - HINT_MIN)/(HINT_MAX-HINT_MIN)</p>
<p>に変換する。</p>
<p>出力：</p>
<p><br />INSIDE / OUTSIDE</p>
<p>### 真の接点計算</p>
<p>environment はプロローグステージで入力された <br />真円パラメータ</p>
<p>target_x <br />target_y <br />target_r</p>
<p>から、x軸との交点（接点を含む）を計算する。</p>
<p>接点は以下の式で求める。</p>
<p>x_a = target_x - √(target_r² - target_y²) <br />x_b = target_x + √(target_r² - target_y²)</p>
<p>接点の順序を保証するため、以下のように定義する。</p>
<p>target_left = min(x_a , x_b) <br />target_right = max(x_a , x_b)</p>
<p>計算された値は</p>
<p>state_environment.py</p>
<p>に保存する。</p>
<p>mentor はこの値を使用して収束判定を行う。</p>
<p>---</p>
<p><br />mentorの役割：</p>
<p>・収束判定</p>
<p><br />## NN005 収束判定</p>
<p>NN005は単一境界 μ を推定するモデルである。</p>
<p>environmentが保持する真の接点を <br />target_left , target_right とする。</p>
<p>NN005の推定境界 μ005 が</p>
<p>| μ005 - target_left | ≤ 1.1 <br />または <br />| μ005 - target_right | ≤ 1.1</p>
<p>を満たす状態が **20ターン連続**した場合、</p>
<p>NN005は収束したと判定する。</p>
<p><br />## NN007 収束判定</p>
<p>NN007は二次関数</p>
<p>f(x) = ax² + bx + c</p>
<p>を用いて推定境界を生成する。</p>
<p><br />### 接点計算</p>
<p>判別式</p>
<p>D = b² - 4ac</p>
<p>を計算する。</p>
<p><br />D &lt; 0 の場合</p>
<p>実数解が存在しないため <br />そのターンは **収束判定を行わない。**</p>
<p>収束カウントは **リセットする。**</p>
<p><br />D ≥ 0 の場合</p>
<p>接点を以下の式で求める。</p>
<p>x1 = (-b - √D) / (2a) <br />x2 = (-b + √D) / (2a)</p>
<p><br />### 接点の順序</p>
<p>x1 , x2 の大小関係は保証されないため <br />以下のように定義する。</p>
<p>left_estimate = min(x1 , x2) <br />right_estimate = max(x1 , x2)</p>
<p><br />### 真の接点</p>
<p>environment は <br />真の接点</p>
<p>target_left <br />target_right</p>
<p>を保持している。</p>
<p><br />### 誤差判定</p>
<p>以下の条件を同時に満たす場合</p>
<p>| left_estimate - target_left | ≤ 1.1 <br />| right_estimate - target_right | ≤ 1.1</p>
<p>NN007は **正しい境界推定**を行ったとみなす。</p>
<p><br />### 連続ターン条件</p>
<p>上記条件を **20ターン連続**で満たした場合、</p>
<p>NN007は **収束した**と判定する。</p>

<p><br /># 10. GUI仕様</p>
<p>GUIは **高校の授業の可視化用途及びデバッグ**で使用する。</p>
<p>画面構成：y軸方向上から順に<br />GUIライブラリ : pygame<br />┌────────────────────┐<br />│ NN007/円_x軸接点探索ゲーム │ # ←固定テキスト<br />│ ゲームの説明　│ # ←固定テキスト（今はこのtextのままでいい・デバッグで修正（校正）） <br />│ １層モデル（1列目）　２層モデル（2列目）　 │ # ←固定テキスト（2列中央寄せ。だいたい後述のxy座標の上部中央に来るようにできるはず）<br />│ １層モデル用xy座標（1列目） ２層モデル用xy座標（2列目） │ #描画（2列） 推定 μ の位置を更新<br />│ （「メンター収束判定！」を表示する行）│ # （2列）←『メンター収束判定！』を表示予約テキストエリアとして空けておく<br />│ ウインドウを閉じる場合は下のボタンを押してください　│ # ←固定テキスト（中央寄せ）<br />│ CLOSE │ # ←pygame CLOSEボタン（中央寄せ）<br />└────────────────────┘<br />描画でレイヤー層が重なる「 １層モデル用xy座標（1列目） ２層モデル用xy座標（2列目）」関係について <br />レイヤー層の下から順に<br />ウィンドウ全体の背景色は標準の明灰色<br />１層モデル用xy座標（1列目） ２層モデル用xy座標（2列目）の　各座標サイズは縦横300px<br />各xy座標の背景は黒色<br />xy軸の各線は、各xy座標の中央配置で、明灰色1px<br />各xy軸に、原点0とミドルレンジを表す-50,50を常時表示、色は明灰色<br />秘密の円は赤色2px<br />過去ターンの推定境界値は青色2x<br />当該ターンの推定境界値は黄色2px <br /><br />1ターンごと、GUIリアルタイム更新とする。</p>
<p>学校のロースペックPC環境でのGUI実行において描画速度を確保するため、ターン毎に表示の書き換えを必要とする項目（ターン数やNN計算内容）は表示させない方針を採る。</p>
